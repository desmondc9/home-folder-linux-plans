# 每日全球机构研究报告扫描（cron 任务提示词）

你今天运行在 Asia/Shanghai 时区，日期以运行时上下文为准。本任务全程无人值守：搜索下列机构在过去 7 天内发布的新研究报告，为每份新报告撰写详细中文摘要并归档。**你的最终回复必须是当日简报全文本身**（会直接送达用户 Kimi 私聊），不是计划、确认或进度汇报。

## 执行步骤

1. 先列出 `/home/desmond/reports/全球机构研究报告库/` 下已有文件夹（含 `日报/` 子目录），建立「已存在报告」清单用于去重（同机构同主题即视为已有，不受中英文命名差异影响）。
2. **先读 `/home/desmond/reports/全球机构研究报告库/来源目录.md`**，按目录直达源逐类逐机构检查（直达优先、搜索兑底）：
   - **RSS 源**：用 exec `curl -sL '<feed 地址>'` 拉取并解析近 7 天条目（pubDate 对照今天）；一次拉取无近 7 天条目 → 该机构直接记「无更新」，进入下一家；
   - **列表页（fetch）**：用 web_fetch / web-reader 打开，读最新内容的官方日期；无近 7 天新报告 → 记「无更新」；
   - **列表页（browser）**：用 browser 工具打开（单页 90 秒预算），看最新日期；无近 7 天 → 记「无更新」；
   - 直达源失效（404/超时/Cloudflare 且 browser 也失败）→ 降级 web 搜索，并在日报「失败名单」注明「直达源失效」；
   - 目录标「搜索」或未登记的机构 → 直接走 web 搜索（工具固定 zai 那套：web-search-prime + web_fetch / web-reader；禁用 web_search kimi 后端）。
   只收研究报告类内容，不收新闻稿、博客短文、活动公告。命中候选报告后仍按第 3 步打开原文页确认发布日期。
3. 对每份候选报告：打开原文页面或 PDF 确认发布日期确在近 7 天内；发布日期以官方页面/PDF 标注为准，拿不准就放弃该条；若已存在清单里有同机构同主题文件夹则跳过。**遇到官方页 403/Cloudflare 拦截或 JS 渲染读不到内容时（如 mckinsey.com、goldmansachs.com/insights、艾瑞报告列表、WEF PDF），优先用 browser 工具（网关托管的 headless Chrome，已安装验证可用）打开该官方页：browser open 后用 text/navigate 提取内容与日期；单页浏览器操作总预算 90 秒，超时或仍失败立即降级回 web 搜索与二手来源路径；用完关闭 tab；不得用浏览器绕过付费墙或登录墙。**
4. 阅读原文，撰写详细中文摘要（500-800 字，覆盖：报告背景与主题、核心观点、关键数据与图表结论、趋势判断、对策建议）。PDF 可用 exec curl 下载后 `pdftotext` 提取文本（已安装）；网页原文用 web_fetch / web-reader 读取。拿不到原文时，搜索其他媒体的转载、读后感、评论等资料作为替代信息，并在 summary.md 中明确注明依据的是二手来源。
   摘要必须执行**信号规则**：(a) 头部新增一行「**信号强度**：高/中/低——一句话理由」，高=含新数据且出现首词/拐点或可能偏离市场认知，中=有价值的新数据但无拐点，低=常规研究/知识性内容；(b) 核心数据必须带参照（环比/同比/上期值/历史极值），出现「首次/创纪录/连续 N 期逆转/明显加速减速」必须显式标注；(c) 信号强度为高的报告，在对比章节之前增加「## 影响链条」一节：该数据/趋势使上游、下游哪些环节受益、哪些承压（产业影响映射，不构成投资建议）。
5. 每份报告保存为一个文件夹：`/home/desmond/reports/全球机构研究报告库/YYYY-MM-DD-[机构英文名]-[中文主题]-[english-topic]/`
   - 日期 = 报告发布日期（不是扫描当天）；
   - 主题必须中英双语，中文在前、英文短名在后，英文用连字符小写词组；例：`2026-08-25-Gartner-新兴风险报告AI漏洞-emerging-risks-2q26`；
   - 文件夹内含 `summary.md`（开头标注：报告中英标题、机构、发布日期、原文链接；正文为中文详细摘要）；若能获取公开 PDF 原文，同时保存原文件（文件名用报告英文原名）。
   - `summary.md` 末尾增加「## 与历史类似报告对比」一节：在库内检索同机构或同主题的历史报告（读其 summary.md），归纳相同点、不同点与趋势规律；确无类似报告则明确写「库中暂无类似历史报告」，禁止虚构对比对象。
6. 全部机构扫描完毕后，把当日简报写入 `/home/desmond/reports/全球机构研究报告库/日报/YYYY-MM-DD.md`（用扫描当天日期），内容包含：①**「今日雷达」**——高信号报告 2-3 份，每份附信号理由（含首词/拐点与关键数字）与影响链条一行；当日无高信号报告则如实写「今日无高信号报告」；②**新增报告逐份详述**——每份含：发布日期、中英文标题、机构、信号强度、精炼中文摘要（150-300 字，完整版在 summary.md）、与历史类似报告的对比结论（相同点/不同点/趋势规律；无则如实写明「无类似历史报告」）、归档路径与原文链接；③跳过/无更新统计；④无法访问或失败的机构名单；⑤（可选）前瞻提示（已知即将发布的重磅报告）。日报写完后，在文件末尾追加一行哨兵标记：`<!-- SCAN-COMPLETE -->`（供后续晨报任务确认扫描完成）。**你的最终回复只需一行：`DONE 新增N份`**（本任务不直接向用户投递；用户简报由 07:15 的 Kimi 晨报任务基于你落盘的日报与 summary.md 生成）。
7. 回复前的硬校验：用 exec `ls` 列出库目录当日新建文件夹，与日报「新增报告」逐行比对（机构+主题一一对应）；日报里只允许出现磁盘上真实存在的文件夹；表格里有多余的、或文件夹名对不上的，必须先修正日报再回复。禁止在日报里提及未实际归档的报告。

## 效率与稳健性要求

- 任务量大（约 50 家机构），按七大类**顺序逐类自跑**，每类内逐机构完成：搜索 → 确认日期 → 去重判断 → 读原文 → 写 summary.md 落盘；一类完成再进入下一类，全部扫完再写日报。**禁止使用 sessions_spawn / sessions_yield 等子任务派发或让出回合的机制**——无人值守隔离运行中让出等待子任务会导致运行提前结束（2026-09-03 首扫即因此半途而废）。每家机构搜索控制在 1-2 次查询，读原文优先官方页面，单家机构最多 5 分钟，超时记入失败名单继续下一家；总时长上限 4 小时。
- 严格去重：同一报告（同机构同主题）已有文件夹则直接跳过。
- 优先使用官方来源（机构官网、官方 PDF）；引用二手转载必须强调并注明。
- 单个机构官网打不开或搜索失败（含浏览器降级也失败），记入「失败名单」后继续下一家，不要卡死重试。
- 简报与 summary 正文全部用中文写作，机构名、报告名保留英文原名。如当日确无任何新报告，简报如实说明并给出七大类的核查结论。
